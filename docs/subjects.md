# 主体与附件

选择一个 FBX 或 PMX 后，插件记录本次导入的模型根、骨架、网格、材质槽和源数据。角色主体参与出图，已识别的武器、风之翼和技能附件由侧栏 **附件** 勾选。脸、眼睛、头发、服装及角色装饰保留。

## 操作

- 展开 **附件**，勾选需要出图的部件，相机随之构图。
- 点击 **调整分组**，选择部件用途与是否出图；没有附件面板时从导入按钮旁的菜单打开。
- 分组窗口确认后生效；取消保留原状态。显示与分组支持 Blender 撤销、重做和保存重开。
- **恢复导入状态** 还原原始网格、材质引用及显示。PMX 恢复到自动骨骼修复后的导入基线。

多角色场景先选当前角色，选择与输出仅作用于该导入批次。

## 识别与保护

分类使用实际源材质命名空间、蒙皮权重、骨骼层级、对象用途和连通表面。MMD 的边线与顶点顺序组不计作蒙皮骨；物理辅助对象、占位网格和未启用表情层保留数据。无法判断的表面保留原可见状态，可在分组窗口纠正。

独立对象切换显示；同一网格内的混合部件写入派生面属性，由自有几何节点控制渲染表面。原网格不拆分，骨架不重绑，原 UV、法线、顶点色、权重、形态键与动画引用保留。恢复移除本插件的筛选节点并还原数据引用。

构图使用当前姿态下的启用表面，描边不扩大构图范围。关闭的附件不参与图片输出，勾选后保留源模型的位置和挂接；原资产中的独立附件尚未装到角色身上时，仍在其原位置出图。

附件沿用导入材质。场景没有灯光且启用了原材质表面时，输出副本为这些对象补充临时定向光；原场景和材质不变。本阶段不增加武器专属着色或自动装备。

## 已有工程

0.5.3 保存的工程保留原来的材质和显示行为。需要使用部件管理时，重新导入模型建立部件记录；插件不会在打开旧工程时自行改组。
