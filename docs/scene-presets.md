# 场景预设

展开默认折叠的“场景”面板，选择 **城市露台** 或 **舞台**，点击 **载入**。空场景、已有模型都可使用，不需要先导入或应用材质。

| 预设 | 内容 |
|---|---|
| 城市露台 | 2.3.0 原布局的露台、护栏、水面及城市远景；3 盏灯、世界，3 张贴图内嵌 |
| 舞台 | 完整 360° 星空与顶部、中央圆台、发光环和外围地面；3 盏灯、世界，无外部贴图 |

载入后，在独立的 `HGT • 城市露台` 或 `HGT • 舞台` 集合中编辑布景；“灯光”选中预设主光，相机保持当前场景选择，不创建额外相机。没有相机时，由模型导入或“相机对齐当前视角”创建默认相机。已有角色保持原位置、尺寸、材质、骨架和动作；构图可通过原生相机工具调整。城市露台保持原布局与尺寸，不按角色缩放。

舞台中央圆台直径约 6.8 米，外围地面及背景延伸到半径 10 米。星空覆盖完整圆周，顶部延伸封口；背景与星点使用内向面及背面剔除，相机处于环外时可透过近侧背景背面。背景尺寸与角色、中央舞台独立，极端俯仰或超出范围的镜头仍应检查画面边界。星点保留 22,000 个四边面，并未按环绕角度重复叠加原网格。

选择另一项并点击“载入”即可切换；重复载入当前项不重复追加。右侧 **×** 移除预设，并恢复进入预设前的世界和主光。载入后手动改选的设置会保留。后来加入预设集合的对象、集合，以及复用到其他位置的资产均会保留。

2.11.0 前载入的预设，在主动载入或移除时处理原参考相机。如果它已承载 MMD 相机运动，会保留整个动画相机及其数据、动作、驱动和父级，接管为默认相机并更新原默认相机引用；闲置参考／总览相机安全清理。`MMD_Camera` 控制空物体保留。多台预设相机含动画、默认相机也有动画或被其他场景复用时，明确提示冲突；用户自建或外部复用的相机不会批量删除。安装新版不会自动重建正在打开的舞台。

载入时暂时关闭当前场景独占的插件打光，移除后恢复；启用打光预设可重新使用它及之前的参数。其他已有灯光保留，仍参与渲染。预设使用一盏主光驱动角色 Toon／SDF 方向，补光继续参与场景照明。

预设不会自动随 PMX 导入载入，不改变输出尺寸、路径、帧率或工程原有合成。舞台工程中的原后期不作为此模块的一部分。原始 `City-Terrace` 与 `HSR-Scene` 文件只读，运行时使用插件内的干净资产副本。
