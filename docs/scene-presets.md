# 场景预设

在“场景预设”选择 **城市露台** 或 **舞台**，点击 **载入**。空场景、已有模型都可使用，不需要先导入或应用材质。

| 预设 | 内容 |
|---|---|
| 城市露台 | 缩小的半环地面、护栏、水面及弧形远景；3 盏灯、正面参考相机、世界，3 张贴图内嵌 |
| 舞台 | 星空背景、舞台和地面装饰；3 盏灯、参考相机及总览相机、世界，无外部贴图 |

载入后，在独立的 `HGT • 城市露台` 或 `HGT • 舞台` 集合中编辑布景；“相机”和“灯光”会选中该预设的参考机位与主光。已有角色保持原位置、尺寸、材质、骨架和动作；构图可通过原生相机工具调整。城市露台载入时按所选模型的高度和脚部位置匹配布景，未选择模型时使用标准尺寸；半环护栏半径 2 m、弧形远景半径约 3.36 m，再按模型高度缩放。远景使用保留在网格上的投影坐标，主要面向正面参考相机。

选择另一项并点击“载入”即可切换；重复载入当前项不重复追加。右侧 **×** 移除预设，并恢复进入预设前的世界、相机和主光。载入后手动改选的设置会保留。后来加入预设集合的对象、集合，以及复用到其他位置的资产均会保留。

载入时暂时关闭当前场景独占的插件打光，移除后恢复；启用打光预设可重新使用它及之前的参数。其他已有灯光保留，仍参与渲染。预设使用一盏主光驱动角色 Toon／SDF 方向，补光继续参与场景照明。

预设不会自动随 PMX 导入载入，不改变输出尺寸、路径、帧率或工程原有合成。舞台工程中的原后期不作为此模块的一部分。原始 `City-Terrace` 与 `HSR-Scene` 文件只读，运行时使用插件内的干净资产副本。
