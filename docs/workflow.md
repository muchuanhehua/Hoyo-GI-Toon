# 场景模型与材质渲染

面板直接显示模型、材质、场景预设、灯光、相机和渲染入口。按已有工程操作，不要求先经由插件导入。

## 已有 MMD 模型

选中模型的网格、骨架或 MMD 根对象，面板自动识别所属模型；也可在“模型”中选择。点击“应用材质”后生成自有渲染资源和恢复记录。已有模型不重新导入、不重复修复骨骼，原有动作、Morph、物理及对象层级保留。

资源直接读取工程中的原材质和贴图引用，支持打包贴图，无需重新选择源 PMX。缺图时使用菜单中的 Blender 原生“查找丢失贴图”。

## 导入新 PMX

“导入 PMX”调用 MMD Tools 并自动修复骨骼。导入保留原结构和显隐，不应用渲染材质、不布光、不构图或切换视图；场景没有相机时创建一个，已有相机保留。

## 材质

“应用材质”按 PMX 的基础图、Toon、Sphere、Alpha、双面和源边线装配。同步 Eevee／Standard 的 Toon 渲染条件，使预览和原生渲染采用同一材质链路；相机、尺寸、路径和原合成设置保留。

- “阴影位置”控制当前模型的明暗分界。
- “脸部阴影软硬”调整 SDF 脸部阴影的过渡，有对应材质时显示。
- “描边粗细”调整有效源描边的宽度。
- 材质列表决定下方颜色、阴影颜色和描边颜色的作用对象；无效参数按材质语义隐藏。
- “重置材质参数”恢复当前模型全部材质的初始参数。
- 菜单中的“恢复原材质”撤回派生材质和网格，模型、独立灯光和相机保留。

SDF 自动读取同角色 FBX 资源包的材质 JSON 与明确贴图引用。没有对应资源时保留基础阴影；多份资源或明确引用缺图时给出错误。菜单中的“选择脸部资源”可指定资源包、Materials 或 Textures 目录，取消不改当前选择；更换资源或采用本次解码时，先恢复原材质，再应用材质。旧式 FaceLightmap 读取 Alpha，新式 FaceSDF 使用 R/A 重建主阴影；完整游戏算法仍在验证。

## 打光

需要布景时，先在“场景预设”选择城市露台或舞台，点击“载入”；它会设置预设的相机、主光和世界。切换及移除规则见 [场景预设](scene-presets.md)。模型导入仍与场景载入独立。

无需模型即可点击“默认光”，创建或复用本场景的默认太阳光。再次调用恢复预设方向和强度。“灯光”支持一盏太阳光、面光、点光或聚光；太阳光使用方向，其余取当前角色头部到灯光的代表方向。每个角色分别更新，SDF 不合成多灯阴影。

## 相机与视线

“相机”直接使用 Blender 当前场景相机。先在普通 3D 视图选好角度和远近，再点击“相机对齐当前视角”；没有相机时创建一个。相机视图中直接调整相机即可。

“看向相机”按需启用，眼球实时跟随当前场景相机及头部、换帧变化；关闭后恢复原眼骨控制。已有 MMD 模型无需应用材质也可使用视线。

## 原生渲染与 MMD

“渲染”调用 Blender 原生当前帧渲染，使用当前场景的相机、可见模型、灯光、合成和原生输出设置，结果显示在 Render Result。保存图片、设置分辨率和动画输出使用 Blender 原生功能。插件没有独立输出面板，不创建临时渲染场景、自动保存 PNG 或附加后期。

表情、动作和物理由 MMD Tools／Blender 管理。当前已验证骨骼动作、顶点 Morph 动画、原数据及 MMD 元数据保护；材质／组 Morph、完整 VMD 和物理演出仍需专门验证。
