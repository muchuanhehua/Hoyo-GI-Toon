# 场景模型与材质渲染

面板分为角色管理、材质、局部调色、附加效果、场景、打光、相机七块，均可独立展开；场景和打光默认折叠。按已有工程操作，不要求先经由插件导入。

## 已有 MMD 模型

选中模型的网格、骨架或 MMD 根对象，面板自动识别所属模型；也可在“模型”中选择。点击“应用材质”后生成自有渲染资源和恢复记录。已有模型不重新导入、不重复修复骨骼，原有动作、Morph、物理及对象层级保留。

顶行依次为“导入模型”、完整角色选择框和骨骼眼睛按钮。选择框只列出具备骨架和渲染网格的 MMD 根主体。资源读取工程中的原材质和贴图引用，支持打包贴图，无需重新选择源 PMX。缺图时使用 Blender 原生“文件 → 外部数据 → 查找丢失文件”。

## 导入新 PMX

“导入模型”调用 MMD Tools 导入 PMX 并自动修复骨骼。导入保留原结构和显隐，不应用渲染材质、不布光或切换视图；场景没有相机时按模型尺寸创建正面全身相机，已有相机保留。眼睛按钮只切换所选角色的骨架视口显示。

## 材质

首次“应用材质”按 PMX 的基础图、Toon、Sphere、Alpha、双面和源边线装配，并自动启用材质预览，使用场景灯光与世界。之后调参直接更新预览，无需重复点击应用。同步 Eevee／Standard 的 Toon 渲染条件；相机、尺寸、路径和原合成设置保留。

- “整体阴影软硬”为 0 时保留二分阴影；数值增大，只柔化身体、头发和脸部的原明暗边界，亮暗颜色和纹理细节保留。高级选项中的“脸部软硬补偿”调整脸部柔化宽度，默认 1，0 保留脸部硬边。
- 阴影方向跟随所选主光；高级选项中的“明暗分界偏移”用于艺术微调，0 保持默认分界。
- “描边粗细”调整 Toon 描边宽度，滑条 0–5，可输入更大数值；0 关闭。源 PMX 未启用边线的普通外表面仍生成描边；内层标记及重合反向薄面不生成回退外壳，源材质明确开启的可见边线保留。眼睛、眉睫、透明表情和加亮叠层继续排除。
- “上下描边差”用一个滑条同时调整上下比例：0 上下等粗，正值上粗下细，负值上细下粗；保持平均比例和单独的“描边粗细”，沿静止高度自动平滑过渡。不再显示顶部比例、底部比例或渐变编辑器。旧工程保留已调外观，第一次拖动新滑条时改用统一平滑过渡。高度随蒙皮与动作移动，不重写静止高度和内层面选择。
- “局部调色”中的材质列表决定该面板内颜色、亮度、饱和度、不透明度、阴影颜色和描边颜色的作用对象。插件不透明度乘在源 Alpha 上，不显示原本全透明的表情。
- “重置参数”恢复当前模型全部材质的初始参数。
- “材质”中的“恢复原材质”撤回派生材质和网格，模型、独立灯光和相机保留。

“脸部 SDF”提供自动匹配、基础阴影及 11 种内置组合。手动选择内置组合无需外部 FBX；切换即时更新全部脸部皮肤材质，保留已调参数，其他材质和原模型保持。内置数据图自动打包进工程。自动匹配仍根据配套材质的明确引用选择相同内置图；没有配套资源时保留基础阴影，资源歧义或损坏时显示错误，可改为明确的内置组合。旧式读取 Alpha，新式使用 R/A 重建主阴影；完整游戏算法仍在验证。

## 附加效果

“辉光”位于“局部调色”下方的独立面板，默认关闭。采用 MAVR 式原生全画面后期，人物、其他角色与背景中超过亮度阈值的部分均可产生光晕。无需选定人物，直接处理当前已经渲染的画面。

开启后使用 **模式** 下拉选择：

| 模式 | 效果与专用参数 |
| --- | --- |
| 辉光 | 常规柔和光晕，默认模式；可调扩散范围。 |
| 鬼影 | 镜头反射般的光斑；可调迭代次数与色彩变化。 |
| 光条 | 放射光条；可调数量、角度、迭代、衰减与色彩变化。 |
| 雾辉光 | 雾状扩散；可调扩散范围。 |
| 简单星芒 | 十字或对角星芒；可调迭代、衰减与对角方向。 |
| 阳光束 | 从画面指定位置向外延伸的光束；可调扩散范围与光束中心，中心坐标为 0–1，0.5 为居中。 |
| 卷积核 | 使用默认柔光核或自选卷积图像生成光斑；默认核内嵌工程，无需额外文件。自选图像按 Blender 原有图像路径／打包方式保存。 |

七种模式均根据完整画面的高亮产生效果，光晕、鬼影和光束可以向外延伸。切换模式与参数保存在当前场景，不重建人物材质或额外绘制人物。2.10.0 起作用范围从选定人物扩展为全画面。

- **辉光阈值**：默认 0.85，范围 0–2；降低时更多区域产生辉光。
- **辉光强度**：默认 1，范围 0–2；0 保留原图。
- **扩散范围**：默认 0.5，范围 0–1；调整光晕宽度。

开启后自动启用当前场景视口的合成器预览，参数即时生效，也用于 F12／动画渲染。参数属于当前场景，保存在工程中。关闭时还原原合成连接及此前的视口模式，撤销重做同步恢复；已经手动改选的视口模式保留。共享合成器在修改前分离，其他场景保持。

实时预览使用 Blender 原生视口合成器，与最终渲染共用当前画面的输入。辉光不添加辅助集合或视图层，不注册人物捕获定时器，不执行 GPU／CPU 图像回读；多个视图按各自原生画面处理。

打开旧人物辉光工程时保留模式与参数，迁移为全画面，并移除原辉光拥有的辅助视图层、集合及未被复用的图像。用户新增节点、集合或跨场景复用存在冲突时提示具体原因，保护原数据；解决冲突后重新开启辉光即可迁移。

透明背景会为外侧光晕保留 Alpha，导出透明 PNG 后仍能看到。已有合成器的辉光接在最终图像输出前；开启时 Viewer 预览同一辉光结果，关闭恢复其原输入，用户手动重接的 Viewer 保持。文件输出等其他支路始终保持；原合成器缺少明确的图像输出或辉光输入被手动破坏时会提示修复连接。

### 果冻眼

在“附加效果”点击“果冻眼”，对角色管理中选定的角色启用；每个角色可独立开关和调参，无需先应用 GI-Toon 材质。播放或渲染动画时，原有转眼、头部及眨眼动作继续生效，左右虹膜围绕各自当前中心交替横向／纵向压缩，高光一同变化，眼白、眼睑保持。

- **弹性幅度**：默认 0.55，0 保持原眼睛，1 为最大幅度。收缩最大 24%，不会扩大原虹膜范围；每帧重新投回原动作后的虹膜表面，保留高光原有的表面间距。
- **弹动速度**：默认每秒 1.2 次，范围 0.1–5 次，不改变原动作播放速度。
- **Q 弹程度**：默认 0.35，调整周期内弹动节奏，不增加最大变形范围。

参数按角色保存在工程，实时生效并可添加关键帧；停止播放时停留在当前帧。再次点击关闭时移除本效果，原网格、形态键、权重和动作不变。恢复原材质不会关闭独立果冻眼。

要求明确的一对左右眼骨及独立虹膜材质（如目、眼睛、瞳、Iris、Pupil）；虹膜和高光需明确绑定到对应眼骨。左右眼可在不同网格，但单独的高光需要与对应虹膜合并到同一网格；与非眼睛面共用顶点、骨架前有改变拓扑的修改器等情况会提示原因。启用后改变源顶点数会暂停效果并提示重新启用。此模式约束的是原动作下的虹膜；原动作本身造成的穿模仍需修正原动作。

## 打光

需要布景时，先在“场景预设”选择城市露台或舞台，点击“载入”；它会设置预设的相机、主光和世界。切换及移除规则见 [场景预设](scene-presets.md)。模型导入仍与场景载入独立。

无需模型即可选择默认光、柔和正面、侧面塑形或背光轮廓，再点击“启用”。可调整强度、颜色、光向方位／高度与光源角度；每个预设分别保存参数，重复启用和切换回来均保留。自有灯光常驻，恢复材质不会删除，切换预设复用同一盏灯。

主光颜色同时作用于角色 Toon 颜色；插件预设以默认光强度 2 为基准，外部灯光以选用时的能量（至少 1）为基准，调整强度可直接改变角色亮度。太阳光旋转改变阴影方向，移动位置不改变方向；点光、面光和聚光的位置会改变相对角色的光向。光源角度／尺寸控制场景投影的柔和程度，角色明暗交界使用“整体阴影软硬”。

光向使用角色独立的着色参数更新，旋转光源无需重算描边几何。旧工程打开时自动迁移原参数与光向引用；旧最低软硬值迁移为真正的 0，并保持原二分外观。正值使用修正后的边界柔化。

“灯光”支持一盏太阳光、面光、点光或聚光；太阳光使用方向，其余取当前角色头部到灯光的代表方向。每个角色分别更新，SDF 不合成多灯阴影。已有受管工程打开时会升级插件拥有的参数和描边数据，原模型与材质引用保留。

## 相机与视线

“相机”直接使用 Blender 当前场景相机。先在普通 3D 视图选好角度和远近，再点击“相机对齐当前视角”；没有相机时创建一个。相机视图中直接调整相机即可。

“看向相机”按需启用，眼球实时跟随当前场景相机及头部、换帧变化；关闭后恢复原眼骨控制。已有 MMD 模型无需应用材质也可使用视线。

## 原生渲染与 MMD

“渲染”调用 Blender 原生当前帧渲染，使用当前场景的相机、可见模型、灯光、合成和原生输出设置，结果显示在 Render Result。保存图片、设置分辨率和动画输出使用 Blender 原生功能。插件没有独立输出面板，不创建临时渲染场景或自动保存 PNG；仅在主动开启辉光时接入该效果。

表情、动作和物理由 MMD Tools／Blender 管理。当前已验证骨骼动作、顶点 Morph 动画、原数据及 MMD 元数据保护；材质／组 Morph、完整 VMD 和物理演出仍需专门验证。
