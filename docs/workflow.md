# 场景模型与材质渲染

面板分为角色管理、材质、局部调色、场景、打光、相机六块，均可独立展开；场景和打光默认折叠。按已有工程操作，不要求先经由插件导入。

## 已有 MMD 模型

选中模型的网格、骨架或 MMD 根对象，面板自动识别所属模型；也可在“模型”中选择。点击“应用材质”后生成自有渲染资源和恢复记录。已有模型不重新导入、不重复修复骨骼，原有动作、Morph、物理及对象层级保留。

顶行依次为“导入模型”、完整角色选择框和骨骼眼睛按钮。选择框只列出具备骨架和渲染网格的 MMD 根主体。资源读取工程中的原材质和贴图引用，支持打包贴图，无需重新选择源 PMX。缺图时使用 Blender 原生“文件 → 外部数据 → 查找丢失文件”。

## 导入新 PMX

“导入模型”调用 MMD Tools 导入 PMX 并自动修复骨骼。导入保留原结构和显隐，不应用渲染材质、不布光或切换视图；场景没有相机时按模型尺寸创建正面全身相机，已有相机保留。眼睛按钮只切换所选角色的骨架视口显示。

## 材质

首次“应用材质”按 PMX 的基础图、Toon、Sphere、Alpha、双面和源边线装配，并自动启用材质预览，使用场景灯光与世界。之后调参直接更新预览，无需重复点击应用。同步 Eevee／Standard 的 Toon 渲染条件；相机、尺寸、路径和原合成设置保留。

- “阴影位置”控制当前模型的明暗分界。
- “明暗过渡”调整身体与头发的 Toon 明暗过渡宽度。
- “脸部阴影软硬”调整 SDF 脸部阴影的过渡，有对应材质时显示。
- “描边粗细”调整 Toon 描边宽度，滑条 0–5，可输入更大数值；0 关闭。源 PMX 未启用边线的普通外表面仍生成描边；内层标记及重合反向薄面不生成回退外壳，源材质明确开启的可见边线保留。眼睛、眉睫、透明表情和加亮叠层继续排除。
- “下部描边比例”控制脚部相对头部的线宽，默认 0.35，1 为均匀；渐变按静止姿态的高度记录在派生网格，随蒙皮与动作移动。
- “局部调色”中的材质列表决定该面板内颜色、亮度、饱和度、不透明度、阴影颜色和描边颜色的作用对象。插件不透明度乘在源 Alpha 上，不显示原本全透明的表情。
- “重置参数”恢复当前模型全部材质的初始参数。
- “材质”中的“恢复原材质”撤回派生材质和网格，模型、独立灯光和相机保留。

“脸部 SDF”提供自动匹配、基础阴影及 11 种内置组合。手动选择内置组合无需外部 FBX；切换即时更新全部脸部皮肤材质，保留已调参数，其他材质和原模型保持。内置数据图自动打包进工程。自动匹配仍根据配套材质的明确引用选择相同内置图；没有配套资源时保留基础阴影，资源歧义或损坏时显示错误，可改为明确的内置组合。旧式读取 Alpha，新式使用 R/A 重建主阴影；完整游戏算法仍在验证。

## 打光

需要布景时，先在“场景预设”选择城市露台或舞台，点击“载入”；它会设置预设的相机、主光和世界。切换及移除规则见 [场景预设](scene-presets.md)。模型导入仍与场景载入独立。

无需模型即可选择默认光、柔和正面、侧面塑形或背光轮廓，再点击“启用”。可调整强度、颜色、光向方位／高度与光源角度；每个预设分别保存参数，重复启用和切换回来均保留。自有灯光常驻，恢复材质不会删除，切换预设复用同一盏灯。

主光颜色同时作用于角色 Toon 颜色；插件预设以默认光强度 2 为基准，外部灯光以选用时的能量（至少 1）为基准，调整强度可直接改变角色亮度。光源角度控制场景物件的投影柔和程度，角色的明暗过渡使用材质参数。

“灯光”支持一盏太阳光、面光、点光或聚光；太阳光使用方向，其余取当前角色头部到灯光的代表方向。每个角色分别更新，SDF 不合成多灯阴影。已有受管工程打开时会升级插件拥有的参数和描边数据，原模型与材质引用保留。

## 相机与视线

“相机”直接使用 Blender 当前场景相机。先在普通 3D 视图选好角度和远近，再点击“相机对齐当前视角”；没有相机时创建一个。相机视图中直接调整相机即可。

“看向相机”按需启用，眼球实时跟随当前场景相机及头部、换帧变化；关闭后恢复原眼骨控制。已有 MMD 模型无需应用材质也可使用视线。

## 原生渲染与 MMD

“渲染”调用 Blender 原生当前帧渲染，使用当前场景的相机、可见模型、灯光、合成和原生输出设置，结果显示在 Render Result。保存图片、设置分辨率和动画输出使用 Blender 原生功能。插件没有独立输出面板，不创建临时渲染场景、自动保存 PNG 或附加后期。

表情、动作和物理由 MMD Tools／Blender 管理。当前已验证骨骼动作、顶点 Morph 动画、原数据及 MMD 元数据保护；材质／组 Morph、完整 VMD 和物理演出仍需专门验证。
