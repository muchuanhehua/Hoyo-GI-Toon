# PMX 分步操作

本插件服务于原神角色材质渲染和 MMD 流程，各步骤由用户主动执行。

## 导入和相机

选择 PMX 后调用 MMD Tools 并修复骨骼，记录原数据，创建一个没有预设机位的相机。导入保留原层级、对象显隐、Morph 和动画，不应用渲染材质、不打光、不切换视图。已有场景相机保持独立；插件输出相机可在侧栏选择。

手动摆相机，或在 3D 视图中先选好视角，再点击 **相机对齐当前视角**。导入、材质装配和渲染都不重新构图。

## 材质

点击 **应用材质** 才生成派生网格和渲染材质。材质按 PMX 的实际基础图、Toon、Sphere、Alpha、双面和边线数据装配。

展开 **材质参数**：

- 阴影位置作用于当前角色的 Toon 明暗分界。
- 描边粗细只在模型存在有效源描边时显示。
- 列表选择材质后可调整颜色和阴影颜色；眼睛、眉睫等独立颜色层不显示无效阴影项。
- 选中材质有有效描边时显示描边颜色。
- **重置材质参数**恢复本次装配的参数；**恢复原材质**撤去材质装配，保留已导入模型、相机和独立灯光。

参数只改自有渲染资源，源 PMX、贴图、原材质及源网格保留。

## 打光

打光是可选步骤。点击 **默认光**创建本角色的太阳光；再次调用复用该灯并恢复预设，不叠加新灯。也可在 **灯光**中选择已有太阳光。旋转该灯后，材质光向实时跟随。导入和应用材质均不自动创建灯光。

## 实时视线与 MMD

**看向相机**保持关闭，用户开启后跟随输出相机。相机移动、头部姿态变化、换帧和渲染时更新，仅调整眼球方向并限制转角。关闭后移除自有约束，原眼骨动画和约束保持。

原表情面板用于静帧调节，本版移除；顶点 Morph、动作和 MMD 数据保留，表情继续通过 MMD Tools／Blender 编辑。自动验证范围为骨骼动作、顶点 Morph 动画和数据保护；材质 Morph、组 Morph、完整 VMD 与物理演出链路尚未验证，不计作完整 MMD 兼容通过。

## 输出和工程

输出使用用户相机和图片尺寸，在临时场景使用 Eevee／Standard 的 Toon 输出条件保存 PNG。透明输出沿用 Blender 的胶片透明设置；插件不创建背景或地面。已有世界、灯光与原合成设置保持独立，可选后期只在输出副本中接入。

指定模型资产目录之外的 PNG 路径。成功校验 PNG 后才替换目标文件，取消或失败清理临时资源并保留原图。取消回调与旧图保护有自动验证，原生 Esc／状态栏实际输入未验证。

保存 Blender 工程可保留分步状态、材质参数、相机、灯光和视线。资源移动后可用菜单中的 **重新定位资源**选择移动后的同一 PMX。旧 1.0.1 工程继续使用旧版；本版在新场景重新导入 PMX。
