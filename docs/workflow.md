# 构图与出图

导入本地 FBX 或 PMX 后，选择 **全身、半身、头像**，按需调整阴影和描边，点击 **渲染** 保存 PNG。其余操作放在折叠面板中。

## 构图

**构图** 提供正面、斜侧、侧面与背面，以及水平角度、俯仰和留白。取点使用当前姿态和实际勾选的表面，排除描边外壳；头像以脸部和角色主体为依据，不将远处的武器纳入头像范围。

手动移动角色相机、修改镜头或使用其他相机后，渲染保留该机位。点击三种构图按钮或 **重新构图** 才重新启用角色相机的构图；自动机位会跟随姿态、部件和图片比例更新。用户场景的活动相机不被替换。

## 展示

**展示** 提供柔光、侧光和逆光；仍可调整方位和高度。透明背景可切换为自选纯色，地面只在临时输出场景中生成。自动机位开启地面时使用轻微俯视，手动机位保持原样。

**恢复初始展示** 重置本插件的光照方向、构图、背景和地面。用户的灯光、世界、原场景合成链及渲染设置保留。PNG 使用统一的 Standard 显示；工作视图保留用户场景的显示设置，最终外观以保存的 PNG 为准。

## 表情与视线

**表情** 只显示模型已有的可用形态键，支持名称搜索和强度调节。FBX、PMX 共用此入口；修改作用于派生形态键，保留源形态键、动作及 MMD Morph 元数据。MMD 的 SDEF 辅助键和 FBX 的默认中性键不作为表情展示。

有可识别眼骨时，**看向相机** 添加可移除的视线约束，跟随当前机位与头部姿态，并限制眼球转角。关闭后移除这些约束，原骨架、姿态通道和原约束保留。**重置表情** 还原本插件修改前的表情值、派生驱动状态并关闭视线。

本入口控制已有顶点表情和眼骨，不新增角色专属表情预设，也不替代 MMD Tools 的完整 Morph 编辑器。已有姿态、动画和头部参照继续参与求值，材质光向与眼层使用当前姿态和视向。

## 保存图片

**输出** 提供竖图、方图、横图尺寸，支持自定义宽高、路径和后期。初始文件名取当前角色名；沿用插件生成的保存位置时，已有文件通过编号保留。手动指定的文件名按该路径保存。模型资产目录和已加载贴图受写入保护。

渲染期间显示 Blender 原生任务进度和取消按钮，也可按 Esc。PNG 先写入临时文件，确认格式和尺寸后才替换目标文件；取消或失败会清理临时资源并保留已有图片，可以继续渲染。图片图标打开最近保存的实际文件。

## 工程与资源移动

保存 `.blend` 会保留当前构图、展示、表情、视线、部件及资源记录。旧工程加载时保留原材质和已有机位；选择新的构图操作后才采用当前构图行为。

移动资产目录后，从导入按钮旁菜单选择 **重新定位资源**，指定移动后的同一个模型文件。插件按工程已有记录核对模型、贴图摘要及尺寸，再修正图像和材质记录中的路径；不重新导入或替换网格。源文件内容和原材质引用保留。缺图、错图或模型不同会明确报错。

## 导入器与更新

FBX 使用独立安装并启用的 Better FBX，PMX 使用 MMD Tools。插件核对公开 Operator 和必需参数；缺失或不兼容时给出具体错误。空面板的 **管理扩展** 打开 Blender 扩展设置，**使用说明** 打开项目入口。

已有远程仓库继续使用 `release/index.json`。在 Blender 的扩展设置中同步仓库并更新，按 Blender 提示重启。候选与正式发布分开，正式包由已复验的候选字节生成；历史版本保留。
