# PMX 渲染

选择 PMX 后，MMD Tools 导入模型并执行骨骼修复，HGT 从原材质读取配套贴图。PMX 与 FBX 共用面板、光照、相机和 PNG 输出。

## 导入与恢复

`mmd_importer.import_model` 调用 MMD Tools 的公开接口，导入网格、骨架、Morph、显示框架及物理数据。关闭清理、合点和骨名翻译选项；不额外重定向 IK 或应用固定轴。

随后依次调用 `fix_bone_order`、`fix_bone_issues`。前者重排 MMD 骨骼 ID 与引用并更新追加变换约束，后者检查 MMD 骨名的编码、长度与重复。模型根的 `hgt_mmd_repair` 保留修复前后骨架、静置/姿态矩阵、约束、骨骼 Morph、显示框架和骨骼集合记录。

渲染装配以修复后的导入数据为保护基线。“恢复导入状态”恢复网格和原材质至此基线；撤销导入同时撤销本次导入与修复。源 PMX 和贴图文件只读。

## 材质语义

| 数据 | 渲染用途 |
|---|---|
| 原材质中日文名称 | 识别脸、头发、眉睫、眼睛和身体；不使用角色姓名 |
| `mmd_base_tex` | 原基础色和透明度；无基础贴图的材质保留纯色 |
| `mmd_toon_tex` | Toon 明暗色带，按光照因子采样并钳制边界 |
| 共享 Toon 索引 | 按 MMD 的明确索引读取导入器自带色带 |
| `mmd_sphere_tex` | 按原模式关闭、相乘、相加或使用附加 UV 相乘 |
| 材质 Alpha、基础图 Alpha | 组合覆盖率，保留半透明细节 |
| 双面开关 | 设置背面剔除 |
| 描边开关、颜色与权重 | 仅给启用的分区生成描边，宽度再乘源权重 |

基础色、Toon 和 Sphere 使用独立 sRGB 图像。PMX 未提供游戏 LightMap 时使用中性数据图，并关闭相应 AO、顶点色 AO 和游戏 Ramp 路径；Toon 与 Sphere 不作为 LightMap。

身体和头发复用原生 Festivity 着色路径。缺少游戏脸部 SDF 的 PMX 使用普通 Toon 明暗；眉睫和眼部保留独立基础色与透明层。不透明材质写入深度，具有源 Alpha 或叠加覆盖的材质使用 Alpha 混合，保留同一网格中的眼睛及透明细节。

`+` 叠加材质以亮度限定覆盖，默认星目层透明显示。原 Alpha 为零的表情层保留透明；全部原几何和 Morph 保留，表情操作在后续阶段开发。

## 网格、描边与输出

UV 别名只写到派生网格，原 UV 和附加 UV 不改。混合网格保留原材质槽，通过节点求值筛选描边分区，分批调用原六材质描边节点，再合并求值结果。眉睫、眼睛、透明表情层和源关闭描边的材质不外扩。

头骨按 `Head / 頭 / 头` 等 MMD 语义在本次骨架内识别。刚体、关节辅助网格保留但不参与普通渲染。同目录的其他 PMX 文件保持独立，不因选择一个模型而一并导入。

基础静帧输出使用 HGT 既有临时场景、色彩和 PNG 流程，输出包含当前导入批次的对象及选定相机，保留用户灯光。同一模型文件内的主体与附件保持完整；不同导入批次独立出图。保留物理、骨骼约束、动画与 Morph 所需数据；动作和物理播放工作流另列后续阶段。

## 参考模块与检查

- Gacha Setup `utils/mmd_model_adapter.py`：材质语义、中性数据图、中性阴影及叠加层处理。
- 晨星 Festivity `_head_candidates`、`character_system.py`、眼部与表情处理：骨骼语义、资源归属、透明层。
- Festivity 原生 Body、Hair、Light Vectors 和描边节点：基础明暗、光照和轮廓。

HGT 将这些模块接到格式描述与派生数据接口。参考验证按实际模块重放记录，不将整套参考插件的一键结果计作 HGT 的外观验收。PMX 自带纹理与游戏导出的 FBX 贴图可能不同，两者分别保留各自材质语义。

`tools/verify_pmx.py` 检查三个跨时期 PMX 的修复前后记录、原数据与 MMD 元数据、Toon/Sphere/描边差分、头部跟随、透明 PNG、保存重开、恢复和失败回滚。实际结果与验收状态统一见 `design/DEVELOPMENT.md`。
