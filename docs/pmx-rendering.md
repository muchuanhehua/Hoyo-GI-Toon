# PMX 材质和 MMD 数据

导入调用 MMD Tools 的公开接口，保留网格、骨架、Morph、显示框架和物理。关闭清理、合点及额外轴向重写，再调用骨骼顺序和骨名修复；模型根保留修复前后记录。原 PMX 与贴图只读。

已有 MMD 模型直接识别工程内的根、骨架和材质引用，不重复导入或修复；贴图可以来自文件或已打包的图像。

## 材质输入

| 源数据 | 渲染用途 |
|---|---|
| mmd_base_tex | 基础色和透明度；没有贴图时保留纯色 |
| mmd_toon_tex／共享 Toon 索引 | 明暗色带，使用原引用或 MMD Tools 的对应共享色带 |
| mmd_sphere_tex | 原关闭、相乘、相加或附加 UV 模式 |
| 材质与贴图 Alpha | 覆盖率与叠加层 |
| 双面与边线 | 剔除、有效源描边颜色和权重；源边线关闭时使用 Toon 描边默认值 |

身体和头发使用原生 Festivity Toon 路径；眼睛与眉睫保持独立基础色及透明层。主脸可直接选择内置共用 SDF，或通过明确的同角色 FBX 材质引用匹配，使用原生 Face／Face Factor；未指定且缺少配套资源时使用基础阴影，保持 PMX 的 Toon／Sphere 语义。

SDF 使用 Non-Color／Channel Packed。旧式 FaceLightmap 读取 Alpha；新式 FaceSDF 使用 `(R+A)/2` 重建主阴影，完整游戏算法及 G/B 用途仍未核实。Face Shadow／眼部遮罩与 SDF 分开，辅助眼口材质保持原用途；不把其他角色或体型的图像静默套入当前角色。

`assets/faces.json` 记录 10 张去重 SDF、3 张遮罩与 11 种有效组合、原始图像摘要及引用材质名。手动选择不访问外部 FBX 目录；只重建脸部皮肤材质，复用现有全局控制，保留局部调色、原描边材质、几何描边选择与高度。只替换本角色受管槽位和描边输入，外部复用的旧材质保留；资源错误回滚并在材质面板显示。内置图像自动打包，保存重开不依赖原资源目录。

材质装配使用派生网格和 UV 别名，原 UV、附加 UV、权重、形态键、动作和原材质引用保持。源材质、骨架及 MMD Morph 元数据可与导入基线严格核对。

光向、头部方向、明暗分界和软硬通过每角色唯一的场景着色属性更新，变化时通知依赖图和视口。光源不再通过物体变换驱动网格上的光向属性，旋转灯光不会连带描边几何求值；静态颜色与轮廓控制保留原链路。太阳光读取世界旋转，其他支持光源读取相对头部的代表方向；保留原节点的 Euler 与头部坐标约定。取消材质灯光时沿用最后光向。

“整体阴影软硬”为 0 时走原生最低值路径，保持二分外观和高级脸部补偿。正值通过 `shadow_boundary.py` 柔化边界：身体／头发在同一阈值周围局部过渡，阴影染色与亮面使用同一遮罩，Toon 取原亮暗端点；脸部以 32 个成对对称的邻域采样过滤零值阴影及其 Toon 颜色，保留 SDF 解码、方向和遮罩。漫反射纹理保持原坐标，不参与模糊。高级脸部补偿缩放脸部采样半径，0 保留原硬边。旧最低值迁移为 0，原参数和源数据保留；正值外观采用新的边界柔化。“明暗分界偏移”位于高级选项，0 对应默认阈值；场景投影软硬仍由灯光角度／尺寸控制。

界面仅保留描边粗细和上下描边差。差值为 `(top-bottom)/(top+bottom)`，范围 -1 至 1；拖动时保持原两端的平均比例，上下系数变为 `mean*(1+d)` 和 `mean*(1-d)`，沿静止高度 EASE 过渡。0 为等粗，正值上粗下细，负值相反。旧渐变数据不在更新时重置，首次拖动新滑条才转为两端平滑过渡；旧参数接口和数据只用于兼容，不显示在面板。重置仍恢复原默认 1／0.35，恢复原材质后再次应用保留已调过渡。零比例面不生成外壳，避免零厚度反面仍覆盖透明源表面。静止高度与共用内层保护保持。这是可调的画风近似，不记作游戏描边算法复刻。表情层沿用源 Alpha，不以插件表情滑块接管。

内侧／内衬按中、日、英文的内层标记识别，包括前后缀、编号、叠层后缀与 Blender 编号，不依赖角色名或衣物名白名单。源边线未启用的单面材质还会检查同一网格中近乎重合的反向三角面，仅阻止这些薄面生成回退外壳；普通外表面和源 PMX 明确开启的可见边线保留。

几何判定的面选择与静止高度均记录在插件自有派生网格，随蒙皮与顶点 Morph 保留；原几何、法线和表面着色保持。旧工程自动重建自有描边图，并保留原有高度渐变、线宽与材质参数。

## 验证

`tools/verify_pmx_modules.py`覆盖三份原生导入的 PMX、打包贴图、已有 2.0.0 工程、参数像素差分、原数据、MMD 元数据、骨骼与顶点 Morph 动画、实时视线、恢复和保存重开；`tools/verify_pmx_interface.py`覆盖空场景与已有模型的真实面板、撤销重做、相机和原生异步渲染。

`tools/verify_lighting_controls.py` 使用冻结 2.6.1 的零值颜色参照，覆盖三角色七光向、转头／转身、太阳光滚转、点光和面光；2.5.0 保留为 CPU 更新耗时参照。`verify_shadow_boundaries.py` 检查零值、高级脸部补偿、零半径、正值响应和保存重开；`verify_shadow_colors.py` 检查明暗核心区原色及零半径脸部颜色。真实视口响应、撤销重做及跨角色四视角描边另行回归；独立的视口绘制采样包含 GPU 读回，CPU 更新耗时不等于实际整帧速度。

这些检查不等同于完整 VMD、材质／组 Morph 与物理演出验证，也不替代逐角色游戏外观验收。当前结果见 `design/DEVELOPMENT.md`。
