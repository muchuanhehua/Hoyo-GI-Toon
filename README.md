# Hoyo-GI-Toon

面向原神 PMX 角色的材质渲染插件，以接近游戏内的 Toon 表现、接入 MMD 流程为目标。

直接使用场景中已有的 MMD 模型，也可导入新的 PMX。当前进度、实施清单和验收状态统一见 [开发记录](design/DEVELOPMENT.md)。

## 使用流程

1. 启用 MMD Tools，打开 3D 视图侧栏的 **GI-Toon**。
2. 在 **角色管理** 顶行选择完整角色；也可选中已有角色网格或骨架自动定位主体。新模型使用 **导入模型**，右侧眼睛按钮切换骨骼显示。
3. 首次点击 **应用材质**，随后阴影、描边和 **局部调色** 参数实时预览。材质中的 **脸部 SDF** 可直接选择内置资源，切换后即时生效。
4. 按需在 **附加效果** 开启 **辉光** 或 **果冻眼**，实时调整相应参数。
5. 按需在 **场景预设** 中选择 **城市露台** 或 **舞台**，点击 **载入**。
6. 按需选择打光预设并点击 **启用**，或选择现有灯光。预设参数保存在工程中，重复启用保留调整。
7. 使用当前场景相机，或主动点击 **相机对齐当前视角**；没有相机时会创建。按需启用 **看向相机**。
8. 点击 **渲染**，结果显示在 Blender 原生渲染窗口；分辨率、保存和动画渲染使用 Blender 原生功能。

面板依次为 **角色管理、材质、局部调色、附加效果、场景、打光、相机**，可独立展开；场景和打光默认折叠。模型选择框只列完整角色根主体。已有模型接入读取工程中的材质与贴图，不要求重新选择 PMX、不重复导入或修骨。导入新 PMX 时自动修复骨骼；场景没有相机时创建正面全身相机，保留已有相机和当前视图。

应用及调整材质时自动启用材质预览，使用场景灯光与世界；参数直接更新，无需重复应用。同步 Eevee／Standard 的 Toon 渲染条件，使视口和原生渲染使用同一材质链路。原生渲染保留完整场景和用户输出设置。表情与动作继续使用 MMD Tools／Blender。

**场景预设** 独立载入布景、相机、主光与世界，贴图内嵌。切换替换本插件的上一套布景；右侧 **×** 移除并恢复原设置，保留手动改选和复用数据。导入模型不会自动载入场景。详见 [场景预设](docs/scene-presets.md)。

**附加效果 → 辉光**采用 MAVR 式原生全画面后期，默认关闭，人物与场景中超过阈值的高亮一起产生光晕，不依赖角色选择。支持辉光、鬼影、光条、雾辉光、简单星芒、阳光束、卷积核七种模式，默认普通辉光。阈值默认 0.85，强度 1，扩散范围 0.5；专用参数随模式显示，卷积核可用默认柔光核或自选图像。参数实时预览并保存到场景。关闭时恢复原合成连接与视口设置，支持撤销重做；透明 PNG 同时保留外侧光晕的 Alpha。预览直接使用现有画面，不添加人物专用视图层、额外绘制或图像回读。旧人物辉光保留参数并迁移到全画面，自有辅助资源在没有用户依赖冲突时自动清理。

**材质**集中控制 SDF、整体阴影软硬、描边粗细和上下描边差。阴影方向跟随所选灯光；整体软硬为 0 时保留二分效果，增大时只柔化身体、头发和脸部的原明暗边界，保留亮暗颜色与纹理细节。明暗分界偏移与脸部软硬补偿放在高级选项。场景投影的软硬由光源角度／尺寸控制。

描边只用两个滑条：**描边粗细**控制整体宽度，0 关闭；**上下描边差**控制上下差异，0 上下等粗，正值上粗下细，负值上细下粗。调整差值时上下同时变化，沿静止高度自动平滑过渡。旧工程保持已调外观，拖动新差值时改用统一平滑过渡。零比例区域不生成外壳，保护透明层。源 PMX 未启用边线也能生成 Toon 描边；内层及重合反向薄面不生成回退外壳，正常外轮廓和源启用的可见边线保留。**局部调色**中的材质列表与颜色、亮度、饱和度、不透明度、阴影颜色、描边颜色独立成区。**恢复原材质**还原导入时的网格和材质，独立创建的相机与打光保留。

内置 10 张去重 SDF、3 张遮罩，提供 11 个有效组合。**自动匹配**读取配套资源引用，已内置的组合使用插件资产；也可直接选择对应体型／版本，无需外部 FBX 目录。**基础阴影**关闭 SDF。切换只更新脸部皮肤，保留局部调色、阴影和描边参数；内置贴图自动打包进工程。旧式 FaceLightmap 读取 Alpha，新式 FaceSDF 使用 R/A 重建主阴影；完整游戏算法仍在验证。

操作与限制见 [使用说明](docs/workflow.md)，材质语义见 [PMX 渲染](docs/pmx-rendering.md)，来源见 [模块接口](docs/upstream-baseline.md)。

**附加效果 → 果冻眼**默认关闭，按角色保存。参考 MAVR 的弹动节奏，在原眼骨／Morph 动作之后，左右虹膜围绕当前各自中心交替压缩，高光随动，眼白与眼睑保持。形变始终投回原动作下的虹膜表面，最大范围受原虹膜约束。可调弹性幅度、弹动速度与 Q 弹程度；幅度 0 保持原样，关闭完整移除。无需先应用 GI-Toon 材质；跳帧与动画渲染使用同一求值。需要可识别的左右眼骨和独立虹膜材质；独立高光须与对应虹膜在同一网格，资源歧义时明确提示。
