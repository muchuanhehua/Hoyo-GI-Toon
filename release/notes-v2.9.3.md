# Hoyo-GI-Toon 2.9.3

修复套用动作后，Eevee 预览中角色光向更新和人物辉光带来的额外求值开销。

- 动画着色参数使用 Scene 支持的 TIME 更新，避免全面更新场景。
- 辉光辅助层复用主层角色参数，避免重复刷新；逐帧处理合并为一次对象遍历。
- 保留实时灯光、脸部阴影、局部调色及描边动画。辉光算法、尺寸、采样、相机画框对齐和最终渲染方式保持。

实际 ZIP 的 17 项动画兼容检查通过，3 组代表角色渲染与 2.9.2 像素一致。在同一隐藏进程、同一实际动作工程及 GPU 缓存内，旧版两次预览更新间隔中位数为 1,498／1,464 ms，新版为 972 ms，降低约 34%。这是四线程私有进程的 UI 更新计时，不等同用户播放帧率；原工程的动画、物理及人物辉光的额外绘制仍有开销。

仅做本次改动的增量检查，57 个未变载荷逐字节核对，不重跑全角色。当前打开的 Blender 保存工作并重启后使用新代码。
