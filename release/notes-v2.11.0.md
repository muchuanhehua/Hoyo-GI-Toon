# Hoyo-GI-Toon 2.11.0

舞台改为完整 360° 星空和顶部，保留中央圆台，外围地面延伸到半径 10 米。内向背景使用背面剔除，镜头从环外拍摄时可透过近侧背景背面。

场景预设不再附带或切换相机。主动重新载入或移除旧预设时，保留已承载 MMD 镜头动画的相机、数据、父级和驱动，接管为默认相机，安全清理闲置参考相机；保护共享场景、外部引用、时间轴镜头标记和用户手动选择。

动画预览减少逐帧角色扫描和重复材质／描边更新，头部光向及 Sun 方向改由 Blender 原生驱动求值，避免 Python 写回重复触发场景更新。保留原模型、材质效果、描边算法、动作和物理。

实际 ZIP 的 29 项兼容、7 项相机归属保护和 3 项播放／撤销检查通过。三帧渲染与 2.10.0 像素一致，本批相机全段 1,053 帧迁移误差为 0，舞台六视角已检查。18 个载荷改变、45 个逐字节保持，按增量范围验证。

同一真实动作第 193–228 帧、2100×1193 私有渲染视口、128 采样／光追／合成保持、无丢帧的 A/B/A/B 对照：2.10.0 为 4.32／4.32 FPS，2.11.0 为 5.25／5.22 FPS，约提升 21%；完整环形舞台及单相机为 5.21 FPS。该场景仍未达到流畅播放，原模型／描边的依赖求值仍有开销；这是独立进程测量，不代替用户前台体验验收。

已有 Blender 进程请保存工作并重启。重新载入一次“舞台”才会升级旧布景及处理旧预设相机；安装不会自动改写正在打开的工程。极端俯仰、贴地或超出范围的镜头仍应检查构图，背面剔除只用于舞台背景，不会让角色或地板自动透明。
