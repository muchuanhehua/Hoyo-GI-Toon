# Hoyo-GI-Toon 2.10.0

辉光改为 MAVR 式原生全画面后期。人物、背景与其他角色中超过阈值的高亮均可产生光晕，不再限定选定人物。

- 移除人物专用视图层、额外绘制、GPU 回读与图像缓存；旧人物辉光保留参数并迁移，安全清理自有辅助资源。
- 保留辉光、鬼影、光条、雾辉光、简单星芒、阳光束及卷积核七种模式，支持实时参数、透明光晕 Alpha、保存及撤销重做。
- 修复原合成器有 Viewer 时参数更新但预览未反映的问题。开启时 Viewer 显示辉光结果，关闭恢复原输入，保留手动改线；用户文件输出支路保持。

冻结安装包的 40 项功能检查、10 项真实视口检查通过。七模式 RGB 与独立原生 Glare 对照一致，强度 0 保留原图；原文件输出像素保持，检查了相机平移／缩放、多视图和旧工程迁移。

同一进程、同一实际动作工程及四线程配置下，预览更新间隔中位数：旧人物辉光 958 ms，新版两次 479／477 ms，关闭辉光 479 ms。新版与关闭辉光处于同一波动范围，人物捕获与回读次数为 0，辅助层从 2 层恢复为 1 层。这是私有进程更新计时，不是用户播放帧率；原模型、动作、物理及渲染仍有自身开销。

仅做本次变更的增量检查，没有重跑全角色。52 个未变载荷逐字节核对，移除旧人物捕获模块。保存工作并重启 Blender 后使用新代码；旧工程首次载入会清理原辉光辅助数据，存在用户新增依赖时提示原因并保护数据。
