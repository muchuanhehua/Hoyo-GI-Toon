# Hoyo-GI-Toon 2.3.0

- 内置“城市露台”和“舞台”两个场景，布景、相机、灯光及世界独立载入，城市露台贴图内嵌。
- 增加常驻的“场景预设”选择、载入和移除入口，空场景及已有模型均可使用；模型导入不自动载入场景。
- 切换替换上一套预设，移除恢复原设置；保留手动改选、用户添加及复用的数据。
- 保持角色位置、材质、骨架与动作，输出设置和原合成保持；材质与 SDF 算法沿用 2.2.0。

使用：场景预设 → 选择城市露台／舞台 → 载入。右侧 × 移除；相机和灯光可在原面板中调整。

本次发布检查覆盖三角色材质与 SDF、原数据保护、旧工程兼容、原生渲染，以及两场景载入／切换／移除、撤销重做、保存重开和资源复用。角色外观与完整 MMD 演出继续按开发记录验收。
