# Hoyo-GI-Toon 2.2.0

- 主脸从同角色 FBX 材质引用读取 SDF；旧式 FaceLightmap 使用 Alpha，新式 FaceSDF 使用 R/A 重建主阴影，修正侧后光与背光换边的大块明暗跳变。
- 增加脸部资源目录入口及阴影软硬参数；单主光源支持太阳光、面光、点光和聚光。
- 修正透明表面的重叠方块，更新共用颜色、阴影与描边参数。
- 保留 PMX 原网格、UV、骨架、Morph 和原材质引用；不导入 FBX 几何，不增加角色姓名规则。

新模型：导入 PMX → 应用材质 → 按需调整材质、灯光和相机。

已有受管模型：恢复原材质 → 应用材质，以采用本次解码。

实际安装包已检查三角色材质、SDF 关键光向、保存重开、恢复、撤销重做与原生渲染。新式完整游戏算法、完整 VMD／物理及逐角色外观继续单独验收。
