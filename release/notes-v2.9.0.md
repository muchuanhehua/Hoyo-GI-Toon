# Hoyo-GI-Toon 2.9.0

附加效果新增 **果冻眼**，在已有转眼和眨眼动作上叠加围绕单眼自身中心的 Q 弹形变。

- 左右虹膜各自弹性压缩，高光随动，约束在原动作下的虹膜表面；眼白、眼睑保持。
- 可调 **弹性幅度、弹动速度、Q 弹程度**，按角色保存，默认关闭。幅度 0 保持原样，关闭恢复原眼睛。
- 原骨架、动作、权重、网格及形态键保持。支持实时参数、跳帧、动画渲染、撤销重做及保存重开。
- 与人物辉光、看向相机及材质恢复／重新应用独立配合，不需要先应用 GI-Toon 材质。

入口：**GI-Toon → 附加效果 → 果冻眼**。需要可识别的左右眼骨与虹膜材质；独立高光须与对应虹膜在同一网格。不明确时会提示，保留原数据。原动作自身造成的穿模仍需修正原动作。

支持 Blender 5.2 及以上；PMX 导入使用单独启用的 MMD Tools。既有七种人物辉光模式、材质和描边功能保留。

本版本从已验证的 2.9.0 本地包原样发布；检查范围和证据见仓库开发记录。
