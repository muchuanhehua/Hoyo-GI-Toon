# 辉光七模式 2.8.0

用户确认新增 MAVR 风格的七种模式下拉，所有模式继续仅由选定人物产生效果：辉光、鬼影、光条、雾辉光、简单星芒、阳光束和卷积核。默认普通辉光，保持 2.7.2 外观。

## 行为

- 使用当前 Blender 5.2 原生 Glare 七类型。光条数量／角度、迭代／衰减、色彩变化、星芒方向、光束中心按类型显示；仅支持扩散的类型显示扩散范围。参数直接保存到场景。
- 卷积核默认使用代码生成的 65×65 高斯柔光图，按浮点 EXR 内嵌工程；也可选择已有图像。默认核只归本模块所有，未被引用时清理；不修改或自动打包用户图像。
- 原人物源、材质、透明遮挡及 GPU 预览缓存保持，切换模式复用人物颜色。内部模式常量更新前也分离共享的子节点组，保护原合成器与其他用户。
- 保留旧辉光组，原 2.7.2 活动工程默认按 Bloom 加载；模式切换、保存重开与撤销重做保持参数和节点一致。关闭恢复原图，并清理本模块卷积核。

## 验证状态

源码与实际 ZIP 的原 23 项渲染／数据、6 项模式与 14 项真实视口检查通过。三角色各七模式可渲染，默认辉光与 2.7.2 逐像素一致；旧活动辉光工程经过切换恢复后仍严格一致。七类型的强度 0、保存重开、背景与未选人物排除、专用参数、自选核、共享组隔离及多轮切换清理通过。自然视口各模式均有画面响应，人物缓存绘制数在切换前后保持。

源码／实际 ZIP 的 98 张 RGBA 图严格一致，三角色七模式已按真实 Alpha 叠加深色背景审阅。实际 ZIP 另核对卷积核切回 Bloom 精确恢复，默认核清理通过。最终五个独立测试进程均正常退出，无崩溃或未释放内存日志；本轮没有新的崩溃报告。

## 保留边界

实时预览仍支持单个材质／渲染 3D 视图。鬼影、光条与光束会延伸到人物之外，但仅由选定人物提供高亮源。不同模式的合成计算开销不同；复用人物缓存不等于各模式 GPU 开销相同。复杂空间变换合成和完整物理／动画演出未新增验证。
