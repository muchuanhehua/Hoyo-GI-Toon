# 选定人物辉光 2.7.2

根据用户补充，辉光仅由“角色管理”中选定人物产生。面板位于局部调色下方，默认展开、辉光默认关闭，保留阈值／强度／扩散范围三个参数。2.7.1 的全画面验证包保留作历史。

## 实现

- 同场景增加人物专用视图层，链接原对象，选定人物正常绘制，其他可渲染物体作为 holdout，关闭世界背景但保留照明。完整场景图像保持，再加上该人物的 Bloom；不会把明亮背景或其他人物作为发光源。
- 保留原材质、BLENDED 透明、骨架、修改器、Morph 与同场景物理。根层可渲染物体的链接临时归入本模块集合以便按视图层隔离；关闭恢复根层链接，原对象不复制、不重新装配。
- 原生 F12 使用人物专用层；实时视口使用 GPU 绘制该层并缓存。画面／材质／人物改变才更新，辉光参数直接复用缓存。Eevee 异步编译完成后补绘，避免冻结首帧的旧着色结果。
- 原合成最终图像、Viewer 分支、共享场景、关闭恢复、透明光晕 Alpha 及撤销重做保持。辅助层被用户节点或集合引用时，先报错保护数据。
- GPU 资源在打开工程、撤销重做和退出前清理。退出使用 Blender 的 [exit_pre](https://docs.blender.org/api/5.2/bpy.app.handlers.html#bpy.app.handlers.exit_pre)，处理仍有效的数据；不在 Python 解释器退出后访问 Blender 数据。

## 边界

实时预览支持单个材质／渲染 3D 视图；同时打开多个此类视图时提示暂停该预览，原生渲染仍可用。移动视角、动画和材质变化需要一次人物专用绘制及编译后的补绘；静止和调辉光参数不持续重绘。已存在的合成链保留，辉光源取未经过该链空间变换的人物颜色，复杂缩放／位移／畸变合成尚未验证。

## 验证与交付

源码与实际 ZIP 的 23 项渲染／数据检查、10 项真实视口检查通过；实际 ZIP 另通过奥黛塔的调色联动、场景数组参数刷新、三轮重建和原数据恢复。安柏／纳西妲／奥黛塔关闭后与冻结 2.6.2 严格相同，源码／ZIP 的 32 张 RGBA 图逐像素一致。三角色对照按实际 Alpha 叠加深色底审阅，避免将透明像素中的 RGB 误作背景染色。
