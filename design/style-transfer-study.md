# 画风研究记录（已结束）

研究日期：2026-10-30。对象：本地 MMD Skin & Metal Studio 3.13.0 的已有拆解报告和源码，与 Hoyo-GI-Toon 2.1.0 对照。

用户在查看 D01 组合版与 D02 原版材质对照后，已于 2026-10-30 决定放弃此路线。本文保留技术研究依据，不再作为开发待办；当前安排见 [开发记录](DEVELOPMENT.md)。

## 结论

静态分析认为可以拆出颜色处理与专用着色组件；两轮实际 demo 后，用户未采用该画风方向。正式插件保持原神 PMX 材质还原目标。

参考插件的大部分画风会重新接管 Material Output 的 Surface，并联动分类、绑定坐标、描边、色彩管理、背景或合成器。因此迁移对象应是有效的颜色算法、遮罩和少量专用着色组件，由本项目接口重新组合。

已有拆解、源码索引和手册位于工作区 `research/MMD皮肤材质，画风渲染/`。静态研究核对了 45 个原始文件，32 个 Python 模块完成 AST 与内存语法编译；随后 D01、D02 完成安柏与奥黛塔的组合版、原版材质静帧对照。工程及证据保留于项目私有 `.verification/demos/`，未进入正式插件，未做画风动画验证。

## 十三种画风的迁移方式

| 参考画风 | 可选取的有效部分 | 接入位置与判断 |
|---|---|---|
| 彩铅、手绘 | 双向排线、断笔颗粒、笔压、纸齿露白 | 优先候选。共用颜色处理模块，以基础材质结果为输入；笔触附着模型 |
| 2D 卡通 | 明度归纳、有限色阶、局部压平 | 可作为轻量颜色模块；保留底图图案、眼部高光与原透明度 |
| 纸片人 | 纸纤维、轻微明度变化、纸色混合 | 可做表面纸纹；MMD 动画优先使用稳定表面坐标 |
| 水墨、国画 | 墨阶、积墨、飞白、湿边、淡彩与纸色混合 | 共用绘画模块；最外层统一混合，确保关闭或强度零时回到基础画面 |
| 油画 | 材质笔触、鬃毛纹理、色块归纳；可选 Kuwahara | 分材质与合成两层。画面滤镜需增加角色范围和五官保护遮罩 |
| 晴空动画 | 硬边明暗、肤色调色板、脸部平滑、颜色保护 | 可拆组件；完整效果需要额外的明暗和面部法线接入口 |
| 碧蓝幻想 | 冷暖三层阴影、交界暖色、发束高光、插画配色 | 可拆组件；涉及光照重设计，属于较后阶段的专用着色分支 |
| 幽灵 | 附着身体的高度渐隐与下部染色 | 适合作为独立特效；原透明度乘渐隐，眼睛与描边同步处理 |
| 正常人（自然 PBR）、3D 质感、金属机器人 | 物理皮肤和金属表面 | 属于替代材质路线，不纳入首批“原神基础之后”的颜色画风层 |

上述是迁移方案与优先级判断，不表示已验证等价画面。彩铅与手绘、水墨与国画各有大量共用构图，可按模块复用，再用配方形成不同画风。

## 在本项目中的接入位置

```text
PMX 原材质与贴图
  → 原神基础材质：Toon / Sphere / 阴影 / 基础乘色
  → 可选画风颜色层
  → 现有 Surface Color
  → 原有透明混合与 Blender 原生渲染
```

`material_controls.initialize` 已在 `HGT • Surface Color` 前插入独立乘色；`node_graph.Graph.surface` 将颜色输出与透明混合分开。颜色画风可以接在当前乘色之后，继续使用原有基础材质结果和 Alpha。

参考 `art_nodes.Graph.surface` 输出的是 Shader，且附加衣鞋调色；迁移时要提取颜色运算，形成颜色输入、颜色输出的节点组。参考中的再次受光采样改接已有明暗信号或关闭重复受光，避免把原神阴影乘暗两次。

统一约定：

```text
有效强度 = 画风强度 × 角色范围 × 细节允许遮罩
最终颜色 = mix(基础颜色, 画风颜色, 有效强度)
普通画风最终 Alpha = 基础 Alpha
```

“无画风”直接旁路；强度零应与当时的基础材质结果一致。幽灵另以可控渐隐乘基础 Alpha。关闭画风恢复当前基础参数，保留之前调整的阴影、颜色、描边和相机。

晴空／碧蓝幻想中的脸部虚拟法线、独立肤色明暗和发束高光需要额外信号，不能全部压成最终 RGB 滤镜。可先迁移调色等后置部分，再评估专用着色组件。

需要重算明暗的组件使用并行画风着色分支，计算出画风颜色后再与未改动的基础分支混合，继续满足强度零的返回约定。

## 先补齐的共用接口

### 材质语义和五官保护

当前基础分类足够驱动现有材质，但 `body` 同时覆盖皮肤、衣物和饰品；`face` 也包含眼白、牙齿、口舌等名称。画风层需要额外用途标签，细分脸部皮肤、身体皮肤、眼睛、眉睫、牙齿口腔、衣物和金属，继续依据原材质引用及模型数据。

混合图集再用局部遮罩，不能仅把整张身体材质染成肤色。含义不明确的区域保留基础颜色。眼睛、眉睫、嘴部与小饰纹优先保护；这些是通用材质适配，不按角色姓名增加分支。

### 随 MMD 变形的纹理坐标

排线和笔触使用 UV 或每角色的模型局部绑定坐标，保持相机移动、转头、骨骼运动与 Morph 变化时的表面附着。画布上的屏幕纸纹另有艺术含义，不能代替表面笔触坐标。

绑定坐标和遮罩写入已有的派生网格 `entry.render_data`，原网格、UV、形态键、权重和源贴图保留。坐标按模型局部尺度归一，头部和光向复用本项目控制器，继续按太阳光旋转求方向。

绑定和静态遮罩在应用时建立，逐帧仅更新必要的头部、光向等动态输入。

### 独立状态与资源归属

画风选择、强度和有效参数按当前模型保存，基础参数保持独立；共享节点定义与各模型实例参数分开。选配方得到明确初态，重复切换不累计资源。资源沿用模型 UID，并标明画风阶段。

材质恢复记录和事务沿用现有保护机制。关闭画风只撤去自有画风节点及关联资源；完整恢复原材质仍由已有材质模块负责。画风切换仅调整所选模型，沿用基础色彩管理，保持灯光、相机、世界、分辨率和保存流程独立。

## 油彩合成层

Kuwahara 会处理渲染图像，单独的五官保护不能限定角色范围。本项目使用完整场景原生渲染，油彩滤镜还需角色遮罩，让背景、舞台和其他角色保留原效果。

```text
滤镜混合量 = 角色遮罩 × 油彩强度 × (1 - 五官遮罩 × 保护量)
```

可使用自有 AOV 传递角色和细节遮罩。滤镜接在用户当前合成输出的真实上游，保留原合成链及 Alpha；移除时只撤去自己的节点。透明边缘、多个 View Layer、多角色和逐帧闪烁需实际验证。

它属于可选画风内部组件，继续使用 Blender 原生合成与保存功能，不增加独立输出流程。
