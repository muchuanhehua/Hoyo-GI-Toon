## 用户流程

1. **导入 PMX**：导入、骨骼修复、记录原数据，创建相机。
2. **应用材质**：装配派生材质；进入 **材质参数** 调颜色、阴影和描边。
3. **打光**：按需添加 **默认光** 或选择已有太阳光，并旋转调整。
4. **相机**：用户设置机位，或主动对齐当前视角；按需开启实时 **看向相机**。
5. **输出**：设置尺寸和 PNG 路径，渲染。

简洁流程：导入 PMX → 应用材质 → 调材质、灯光和相机 → 渲染。没有背景、地面或表情编辑步骤。

## 模块接口

| 模块 | 文件 | 职责 |
|---|---|---|
| 导入 | `importers.py`、`mmd_importer.py` | PMX 入口、MMD Tools 和骨骼修复 |
| 资产保护 | `asset_tracking.py`、`project_io.py` | 原数据、归属、回滚、恢复与资源重关联 |
| 材质 | `material_assets.py`、`pmx_materials.py`、`shaders.py`、`node_graph.py`、`sampling.py` | 资源解析、原生节点和 PMX 语义 |
| 参数与描边 | `material_controls.py`、`outlines.py` | 自有材质参数、源边线、重置 |
| 光照 | `lighting.py` | 默认太阳光、材质光向和技术参照 |
| 视线 | `gaze.py` | 独立眼球跟随，保留原动画控制 |
| 编排与界面 | `workflow.py`、`properties.py`、`panels.py` | 分步调用、有效参数和错误提示 |
| 输出 | `rendering.py`、`post_processing.py` | 用户机位、临时场景、PNG 与取消清理 |

来源与接入标准见 [模块说明](../docs/upstream-baseline.md)。

## 验证边界

实际复验覆盖导入与材质分离、原数据与 MMD 元数据、骨骼动作和顶点 Morph 动画、参数像素响应、实时视线、失败回滚、恢复、保存重开及真实界面。保存重开的图片采用严格像素一致性检查，不沿用旧版结果。

材质 Morph、组 Morph、完整 VMD 与物理演出尚未验证；当前不能称为完整 MMD 流程验证通过。取消回调的临时文件清理与旧图保护已纳入检查，原生 Esc／状态栏按钮实际输入单独留待操作验收。游戏内外观仍须对照截图判断。

## 后续顺序

本轮先由用户验收操作和画面。之后围绕共用 PMX 材质完成游戏截图对照与缺陷修复，再补齐 MMD 的材质／组 Morph、VMD 和物理演出验证；完成对应验收后发布和更新。逐角色材质检查与配置最后按角色进行。FBX 与附件管理暂不恢复。
