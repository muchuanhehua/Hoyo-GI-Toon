## 本轮范围

以整份常规角色 FBX 为处理单位，保留其全部导入对象和原有挂接关系。通过一个文件入口调用 Better FBX，再装配本地配套资源并输出图片。

界面以“导入模型、调节外观、渲染”为主线。常用项直接展示，光照与输出设置折叠；需要用户处理的缺失、歧义和错误才提示。

角色单独提取、混合资产自动拆分、武器专用渲染、特殊角色扩展和 PMX，在本轮基础 FBX 验收后另列开发清单。

## 模块边界

| 模块 | 输入 | 输出 | 职责 |
|---|---|---|---|
| 导入适配 | FBX 文件与已核对的 Better FBX 参数 | 本次导入对象、材质、动作等引用 | 调用导入器并检查结果 |
| 资产记录 | 本次导入引用 | 归属清单、原始数据快照、恢复记录 | 数据保护与失败回滚 |
| 资源解析 | 所选资产包与原材质引用 | 材质参数、明确的贴图路径和用途 | 只解析资源，不改场景 |
| 材质装配 | 材质描述与原生模板 | 渲染材质及原材质对应关系 | 应用贴图和参数 |
| 光照与描边 | 资产引用、控制参数、材质关系 | 自有控制器和未应用的修改器 | 光向、脸部阴影和描边 |
| 输出 | 场景、相机、输出设置 | 图片和保存结果 | 构图、渲染与文件输出 |
| 编排与 UI | 用户操作 | 分阶段调用与简明结果 | 顺序控制、错误提示和恢复入口 |

模块沿用适合的现有文件；确有独立职责时拆分。每项实施后登记实际文件与接口。模块来源和选用要求见 [模块来源与接入标准](../docs/upstream-baseline.md)。

本批候选流程组合 01–05，依次接入 Better FBX、资产保护、资源解析、材质和光照描边；每个模块保留独立检查结果，整批提交验收。

## 01 Better FBX 接入

开发内容：

- 从唯一模型导入入口调用已安装的 Better FBX，识别有效 Operator 和实际参数接口。
- 正确传递文件路径及文件列表，支持中文、空格路径。
- 以保留数据为目标设置导入参数，核对骨骼定向、修姿、合并优化、法线、UV、顶点色、形态键和动画相关选项。
- 返回本次新增数据的明确引用；取消、异常及没有网格的结果均给出明确错误。
- 依赖不可用时说明安装或启用要求；不静默替换导入器。

交付物：独立导入适配模块、调用参数记录、后台导入工程和数据报告。

验收标准：

1. 从同一个入口选择 FBX，实际调用 Better FBX 并完整导入。
2. 保留文件中的对象、材质、骨架、蒙皮和表情；源 FBX 与配套文件摘要不变。
3. 参数记录能复现结果，失败时不留下本次导入的残余数据。
4. 用户检查导入工程与结果报告后明确通过。

## 02 资产保护与导入归属

开发内容：

- 以一次导入为一个资产批次，记录全部新增对象、数据、材质、贴图、动作及其关系。
- 在 Better FBX 导入完成后建立数据快照，作为后续装配的保护基准。
- 渲染材质和控制器独立归属；必要的数据适配使用派生副本，保留原引用与恢复入口。
- 原始修改器保持原样；渲染修改器不应用到基础网格。回滚只处理本插件拥有的数据。
- 连续导入与重复装配互不覆盖，选择和活动对象在失败后可恢复。

交付物：资产记录模块、快照与恢复接口、恢复前后数据对照。

验收标准：

1. 装配与恢复前后，基础顶点、拓扑、原始 UV、法线、顶点色、骨架层级与静置矩阵、权重、形态键和动画数据可核对。
2. 原材质引用可恢复，已导入的附属对象与挂接关系保留。
3. 导入两份模型、重复装配和注入失败时，其他资产与场景内容不被改写。
4. 用户确认数据保护与恢复结果。

## 03 配套资产与材质解析

开发内容：

- 从所选 FBX 所属资产包读取材质 JSON、贴图和原材质图像引用。
- 按明确引用解析 Diffuse、LightMap、Ramp、Normal 与模板实际需要的资源。
- 记录 Body、Hair、Face 等材质用途、参数及 Alpha 语义，资源解析和场景装配分离。
- 搜索范围限定在有关联的资产包，重复与歧义不任取第一项；缺失时指明具体资源。
- 不要求用户逐个选择配套贴图；保持源图片和原材质图像设置可恢复。

交付物：资源解析模块、逐材质匹配清单和必要的错误示例。

验收标准：

1. 只选一次 FBX，即可解析配套资源与材质参数。
2. 每个匹配都有明确依据，不串角色、不串材质分区。
3. 色彩空间、通道打包与 Alpha 用途记录清楚，基础色不被当成数据贴图。
4. 用户核对材质与贴图清单后通过。

## 04 原生基础渲染材质

开发内容：

- 整理原生 Blender 可用的基础着色模板及接口，只保留有效资源与实际使用的分支。
- 将材质描述装配为 Body、Hair、Face 及基础眼部、透明分区所需材质。
- 应用本地材质参数、贴图、Alpha 与高光金属参数，保留清晰的原材质对应关系。
- 含贴图的节点路径按需要独立，重复导入和重复装配不串图、不增加重复资源。
- 渲染材质挂载在记录层之上，不改变模型的基础几何、权重和形态键。

交付物：原生节点资源、材质装配模块、接口与资源清单、统一条件预览图。

验收标准：

1. 模板没有未定义节点、断开的必要输出或无效数据输入，所有所需接口真实可用。
2. 身体、头发、脸、眼部、透明边缘能正确显示，无缺图紫色和异常覆盖。
3. 所需高光与金属响应可验证，材质参数改变有对应效果。
4. 数据保护检查通过，用户确认基础材质外观。

## 05 光照与描边

开发内容：

- 为当前导入资产创建独立光照方向、头部参照及必要控制器。
- 头部控制跟随导入骨架，保留骨架原有数据与变换。
- 通过原生几何节点挂载描边，读取对应材质的颜色与参数，保持正确修改器顺序。
- 提供阴影位置、描边宽度和光照方向调节；重复执行更新已有资源。

交付物：光照与描边模块、正面与侧光预览、头部跟随验证工程。

验收标准：

1. 改变光向后明暗与脸部阴影响应正常，旋转头部后控制跟随正确。
2. 描边宽度和颜色正确，眼部、透明部位不被异常描边遮挡。
3. 控制器与描边属于当前资产，不影响另一份导入模型。
4. 用户确认光照、阴影和描边效果。

## 06 相机与图片输出

开发内容：

- 准备基础预览所需的相机与场景设置，已有用户相机与无关场景资源保持独立。
- 在不移动、缩放原模型的条件下完成适当构图。
- 提供图片尺寸、保存位置与透明背景设置，正确保留输出 Alpha。
- 渲染与文件保存分别检查，必要后期作为独立可关闭模块。

交付物：输出模块、可重开的工程和实际保存的 PNG。

验收标准：

1. 模型清楚入镜，头脚不被意外裁切，画面具备可用的基础光照。
2. 输出尺寸、路径和透明背景与设置一致；保存后可打开图片。
3. 已有相机、无关灯光与合成链不被覆盖；自有输出资源可定位。
4. 用户确认构图、图片效果与保存流程。

## 07 简洁面板与错误提示

开发内容：

- 保留一个“导入模型”入口，内部编排已通过的模块。

交付物：可运行面板、真实界面截图、从导入到出图的简短操作演示。

验收标准：

1. 新手完成“选 FBX、按需调节、渲染”，无须另选 Shader、贴图或导入后端。
2. 主面板没有无效状态说明、重复入口和实现细节。
3. 缺依赖、缺资源、匹配歧义与渲染失败时，提示可直接指导处理。
4. 用户亲自检查操作和面板布局后通过。
