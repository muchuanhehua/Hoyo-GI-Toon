# 游戏截图与基础渲染验收

当前实现以统一的源材质协议处理 FBX，不建立角色姓名或编号分支。0.4.1 为本轮验收候选，最终状态以 [开发进度](DEVELOPMENT.md) 为准。

## 已接入的通用路径

| 模块 | 当前实现 | 实际检查 |
|---|---|---|
| 资源协议 | 父开关、强度、空引用与真实缺图分开；高度通道和 UV 分开 | 芙宁娜、玛薇卡的高度图关闭后出现可见变化；停用金属分支不误报 |
| 眼部 | 连通表面按深度区分虹膜与外层，接入层色 Ramp、SDF、高光、Matcap、视向偏移 | 奥黛塔外/内层 200/252 面，桑多涅 200/336 面；源面和槽索引不变 |
| 面料 | 丝袜、丝绸、闪点独立模块，使用各自的源遮罩和强度 | 三项分别关闭后出现像素变化；丝绸未复用丝袜区域 |
| 晶面 | 指定通道遮罩、Matcap、法线、Fresnel 和原色反射 | 独立关闭反射后，指定饰品区域变化，原贴图不改色 |
| 显示参与 | 保留常驻 Avatar 表面，技能附件、光效、占位与默认未启用表情可逆隐藏 | EyeStar 不遮挡普通眼睛，常驻 EffectMesh 不因名称被统一隐藏 |
| 展示 | 同一光向、高度、阴影、描边、Standard 色彩、零曝光与单位 Gamma | 七角色同一条件出图；原场景设置的隔离由集成检查核对 |

## 验收边界

技术运行、源数据保护和外观验收分别记录。图片出现差异只能证明对应功能参与了渲染，不能证明与游戏着色一致。

新增眼部、面料与晶面提供原生 Blender 的静帧近似。游戏运行时动画、引擎 Cubemap 与眼部深度写入未计作已复现。光照、白色衣料亮度、眼部亮点和晶面层次继续以实际截图供用户判断，不使用角色专用曝光、改色或补丁。

## 复现入口

- `tools/verify_development.py`：原数据、派生几何、重复装配、恢复、共享数据、失败回滚与动画夹具。
- `tools/verify_characters.py`：从候选 ZIP 的隔离安装实际导入、两种光向渲染及源文件摘要。
- `tools/verify_material_features.py`：逐项关闭、近景转角、保存重开、源网格与游戏截图摘要。
- `tools/verify_render_surfaces.py`：贴图引用、表情覆盖、透明输出及后期 Alpha。
- `tools/verify_integration.py`、`tools/verify_interface.py`：输出隔离、保存重开、真实面板、撤销重做和异步渲染。

私人模型、截图、工程、配置与报告存放于 `.verification/development/r01-r07/`；不进入 GitHub 仓库或安装包。运行清单从忽略的资产索引读取。
