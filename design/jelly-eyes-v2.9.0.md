# 果冻眼 2.9.0 本地验证

日期：2026-11-07，Asia/Shanghai。当前为本地验证包；未发布、未更新本机扩展或远程索引。

## 行为

用户要求在附加效果加入参考 MAVR 的果冻眼：套用原动作后，围绕单眼自身中心 Q 弹，并限制在原眼睛范围。

- 默认关闭，按角色保存，独立于 GI-Toon 材质。界面提供弹性幅度（默认 0.55）、每秒弹动次数（1.2）与 Q 弹程度（0.35）。
- 在原 Armature 之后、描边之前使用独立 Geometry Nodes。逐帧从原动作求值后的虹膜获取中心与平面，交替横／纵向收缩，最大收缩 24%，不扩大眼球。
- 将目标位置投回当前原虹膜表面；高光保留相对于该表面的原始偏移。眼白、眼睑及其他顶点不参与。仅对眼睛顶点求表面查询。
- 不写原网格、权重、形态键、眼骨或动作。辅助范围数据与节点组由模块拥有；关闭释放自有资源，保护外部复用。与辉光临时视图层的链接一并恢复。
- 使用 Scene Time 与原生参数驱动，无逐帧 Python 处理器或有状态弹簧缓存；幅度 0 精确保留原输入。乱序跳帧、重开及动画渲染使用同一求值。

MAVR 的 `presets/jelly_eye.py` 只用于参考三参数和周期内弹动节奏，没有复用其全眼球形态键缩放。

## 本批验证

源码与实际安装 ZIP 分别完成 **36 项三角色检查、8 项真实 UI 检查、7 项模块兼容检查**。原始记录在忽略目录 `.verification/development/jelly-eyes-20261107/`：

| 证据 | 源码 | 实际 ZIP |
| --- | --- | --- |
| 安柏、纳西妲、奥黛塔 | `source/jelly.json` | `package/jelly.json` |
| 隐藏窗口真实 UI | `ui/ui.json` | `package-ui/ui.json` |
| 其他模块与双角色 | `interactions/interactions.json` | `package-interactions/interactions.json` |

三角色检查实际眼骨动作能改变眼睛姿态，叠加头部运动与原眨眼／双侧闭眼 Morph，覆盖 6 个动作时点、零幅度和乱序跳帧。虹膜顶点距同帧原虹膜表面均小于 3e-6 模型单位；眼白、眼睑与身体顶点精确不变。原动作、网格、UV、权重、形态键、骨架、材质引用保持。零值、关闭、保存重开与 3 轮启停释放、注入失败回滚通过。

真实 UI 覆盖开关与参数撤销重做、材质视口即时响应、原生动画播放、辉光缓存更新及两种开关顺序下的恢复。兼容检查覆盖原生 MMD 材质、恢复／重应用材质、看向相机、无关高光排除、歧义眼骨预检、两名真实角色独立控制及参数关键帧。

24 张源码／ZIP 的原图、启用、闭眼、保存重开与关闭对照图，RGBA 最大误差 **0/255**，见 `pixel-comparison.json`。`comparison.png` 为三角色同帧开关对照；原始 PNG 与测试工程保留。

独立 4 线程后台进程的姿态／修改器求值加坐标读回中位耗时（ms），后续描边关闭；这是 CPU 样本，不代表整场景 FPS：
