# 2.5.0 面板、实时预览与共用 SDF

本轮按用户操作反馈修改界面、预览与资产选择，城市露台仅还原既有版本，后续设计等待用户说明。

## 行为

| 范围 | 结果 |
|---|---|
| 顶行 | 导入模型／完整角色选择框／骨骼眼睛按钮；移除模型显示及工具下拉菜单 |
| 选择范围 | 仅有唯一骨架与渲染网格的 MMD 根主体可列入；视图中点击角色子对象仍同步到所属主体 |
| 分区 | 角色管理、材质、局部调色、场景、打光、相机为六个独立面板；场景和打光默认关闭 |
| 实时预览 | 首次应用后直接调参；场景属性变化通知依赖图与视口，局部颜色仅更新对应材质；调参时启用场景光／世界的材质预览 |
| 描边 | 滑条 0–5，允许直接输入更大数值；0 关闭，静止高度渐变与通用内层保护保持 |
| 城市露台 | 场景库及目录逐字节还原 2.3.0，取消半环与按模型缩放；旧半环仅在再次主动载入时替换 |
| SDF | 内置 10 张去重场、3 张遮罩，组成 11 个有效选项；另有自动匹配和基础阴影 |

## 资产与切换

内置资产来自本地 109 份原神 Face 材质的明确引用；构建时核对 322 份原资源摘要保持。所有文件保持原字节，按内容摘要去重。同名新式 FaceSDF 存在不同场数据、相同场又存在不同遮罩引用，因此按编码、实际字节与 UV 映射组合，不按名称合并。清单见 [faces.json](../assets/faces.json)，版权见 [NOTICE](../NOTICE)。不包含其他游戏脸部资源、模型或角色漫反射图。

手动选择不扫描外部 FBX 目录。切换先准备全部脸部皮肤材质，再更新本角色受管槽位与几何描边的材质输入；保留全局控制、局部颜色、原描边材质、面选择、静止高度与原数据。角色以外复用的旧材质保持；错误回滚选择和资源，并显示原因。内置图像自动打包，已生成的工程可保存重开。

旧式 FaceLightmap 使用 Alpha，新式 FaceSDF 使用既有 R/A 主阴影兼容适配。解码源码与上游着色库保持，本轮不声称完成游戏完整算法。

## 验证入口

当前源码和实际 ZIP 均已通过 `tools/verify_panel_update.py`、`tools/verify_pmx_interface.py`，以及原三角色、2.0.0 工程、场景、SDF 多光向和描边检查。同组合的自动匹配与手动 SDF 选择图像严格一致，三角色都可使用 3.5 描边值并保留可见宽度响应。实际 ZIP 自然绘制的视口阴影／局部颜色响应分别为约 0.361／0.357，无需再次应用或强制重绘。实际包面板和露台／角色图像已查看。[2.5.0 已发布](https://github.com/muchuanhehua/Hoyo-GI-Toon/releases/tag/v2.5.0)，本地与索引同步；54 文件／44 个实际加载函数和当前工程保护核对通过。私有原始结果位于 `.verification/release-v2.5.0/`；[交付记录](delivery-v2.5.0.json)。

本轮描边几何实现及内层判定与 2.4.2 冻结载荷一致，通过代码／AST 核对及 13 个旧工程的正、背、双侧、关闭／默认／较宽对照检查。2.4.2 的 204 文件、87 模型尝试是历史基线，不记作本轮重新执行。完整 VMD、材质／组 Morph 与物理演出不在本轮验证范围。
